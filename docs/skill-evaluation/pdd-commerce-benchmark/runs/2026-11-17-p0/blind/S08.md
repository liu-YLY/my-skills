# 订单支付模块测试用例（第二次运行）

### TC_ORDER_正常下单_001: 正常下单支付

- 前置条件：用户已登录，购物车有商品。
- 测试数据：在售商品。
- 步骤：
  1. 进入购物车结算。
  2. 选择地址并提交。
  3. 完成支付。
- 预期结果：订单提交成功，支付成功。
- 优先级：P0
- 关联需求ID：BR-ORDER-01
