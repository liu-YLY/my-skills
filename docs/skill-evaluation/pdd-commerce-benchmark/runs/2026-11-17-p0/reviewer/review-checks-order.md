# 需求评审检查清单（REV-ORDER 用）

## 1. 开放问题（相关 3 条）

| ID | 主题 | 期望动作 |
|---|---|---|
| OF-02 | 拼单失败退款遇节假日是否顺延未定义 | 识别工作日口径不清；说明对退款时效承诺和客服口径的影响；提出是否顺延及最长到账时间的确认问题。 |
| OF-07 | 不可配送区域清单维护机制未定义 | 识别清单来源与生效时间缺失；说明对下单阻断和用户体验的影响；提出配置来源、更新频率和生效时间的确认问题。 |
| OF-08 | 同一用户同时参与拼单数量上限未定义 | 识别缺少拼单并发上限；说明对库存占用和风控的影响；提出上限、超限提示和释放策略的确认问题。 |

## 2. 风险检查（4 条）

| ID | 检查项 |
|---|---|
| RC-ORDER-01 | 识别支付回调验签、金额校验、重复回调幂等与补偿链路的风险。 |
| RC-ORDER-02 | 识别库存锁定、超时释放、拼单失败释放与并发超卖的风险。 |
| RC-ORDER-03 | 检查拼单成团/失败/退款状态机与优惠券返还规则是否闭环。 |
| RC-ORDER-04 | 识别订单越权、手机号与地址等敏感信息泄露风险。 |

## 如何填 coverage_recall

```text
open_finding_rate = 命中的开放问题数 / 3
risk_check_rate = 命中/部分命中的风险检查加权 / 4
coverage_recall = 0.5 × open_finding_rate + 0.5 × risk_check_rate
```

命中记 1，部分命中记 0.5，未命中记 0。
