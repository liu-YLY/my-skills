# 优惠券功能测试用例（满减券 / 折扣券）

## 一、需求理解（摘要）

**功能概述**：新增满减券与折扣券，覆盖领取、使用、状态流转与退款。

**本次焦点**：满减券使用（§3.1）、折扣券使用（§3.2）、领取与库存（§3.3）、状态流转（§3.4）。

**业务规则**：1. 满减券需订单金额≥门槛；2. 折扣券按实付金额×折扣率，超上限按上限；3. 每券限用一次；4. 到期失效。

**状态规则**：未使用→已使用（核销）；未使用→已过期（到期）；已作废不可逆。

**待确认项**：叠加顺序与上限、退款是否退券、折扣率范围与精度。

**原文问题清单**：

| 序号 | 位置 | 类型 | 描述 | 影响 | 处置 |

| 1 | §3.2 | 缺失 | 未给出折扣率合法范围与精度 | 折扣配置校验 | 待确认 |
| 2 | §3.5 | 缺失 | 退款后券是否退回未说明 | 退款用例 | 待确认 |
| 3 | §3.6 | 模糊 | 叠加顺序与上限未明确 | 叠加用例 | 待确认 |

**信息来源**：用户 PRD、通用电商优惠券模式。
