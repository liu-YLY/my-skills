## 需求理解

**功能概述**：内部自研硬件调测工具，用于连接设备、下发指令、读写寄存器、烧录固件、采集日志与保存配置。

**用户角色**：硬件工程师（本地管理员权限，单用户）。

**业务规则**：1. 同一时刻仅允许一个连接；2. 烧录前必须校验镜像；3. 指令超时后重发，最多 3 次。

**状态规则**：未连接 → 已连接 → 烧录中 → 已连接；烧录中禁止下发普通指令。

**异常规则**：端口占用、设备掉线、镜像校验失败、指令无回包。

**风险分析**：固件烧录与寄存器写入为高风险写操作；连接状态为全模块前置。
