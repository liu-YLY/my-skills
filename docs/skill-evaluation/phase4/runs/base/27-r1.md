### TC_PAY_PAY_001: 支付受理 - 余额充足时扣款成功
- **优先级**: P0　**类型**: functional　**来源**: ai-generated
- **前置条件**: 用户 U-1001 余额 100.00 元；订单 ORD-001 待支付

- **后置条件**: 保留 PAY-001 供退款用例使用

### TC_PAY_PAY_002: 支付受理 - 余额不足时拒绝并提示
