## 测试用例

### TC_NICKNAME_EDIT_001: 昵称 - 保存中文昵称后列表与详情同步更新

- **优先级**: P0
- **类型**: functional
- **需求追溯**: TP-01
- **来源**: ai-generated
- **人工审核状态**: not-reviewed
- **业务背景**: 验证合法中文昵称保存后，列表页与详情页展示新昵称

**前置条件**: 已登录用户 A；位于「个人中心 - 编辑资料」页面；当前昵称为「张三」

**测试步骤**:
1. 在昵称输入框输入「李小明」
2. 点击「保存」
3. 进入用户列表页，找到用户 A
4. 打开用户 A 的详情页

**关键检查点**: 步骤 2 后：页面出现保存成功的提示

**业务结果**: 昵称输入框显示「李小明」；列表页用户 A 的昵称显示「李小明」；详情页昵称显示「李小明」

**后置条件**: 将昵称改回「张三」
