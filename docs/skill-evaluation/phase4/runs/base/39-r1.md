## 测试用例

### TC_WEBHOOK_CREATE_001: 端点创建 - 三项信息齐备后提交并持久化

- **优先级**: P0
- **类型**: functional
- **需求追溯**: TP-01
- **来源**: ai-generated
- **人工审核状态**: not-reviewed
- **业务背景**: 验证 Version、Trigger、Endpoint URL 均已填写时可创建端点

**前置条件**: 已登录具备端点管理权限的账号；打开「Add endpoint」弹窗

**测试步骤**:
1. Version 下拉框选择 `v2`
2. Trigger 选择框选择 `order.created`
3. Endpoint URL 输入 `https://example.com/hooks/order`
4. 点击「Add endpoint」

**关键检查点**: 步骤 4 后：弹窗关闭，页面出现「创建成功」提示

**业务结果**: 列表新增一行，Version 为 `v2`、Trigger 为 `order.created`、URL 为原输入值；刷新后该行仍在

**后置条件**: 保留该端点供后续用例使用
