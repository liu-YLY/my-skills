### TC_001_登录_001: 手机号与正确密码登录成功
- 优先级：P0
- 类型：functional
- 前置条件：已打开登录页；13800138000 已注册，密码为 Test@1234

### TC_002_登录_002: 密码错误时登录失败
- 优先级：P1
- 类型：functional
- 前置条件：已打开登录页；13800138000 已注册，正确密码为 Test@1234
- 步骤与预期：
  1. 在「手机号」输入框输入 13800138000 → 无格式错误提示
  2. 在「密码」输入框输入错误密码 Wrong@9999 → 密码显示为密文
  3. 点击「登录」按钮 → 停留登录页，密码输入框下方显示「账号或密码错误」，页面未跳转

### TC_003_登录_003: 验证码登录成功
- 优先级：P1
- 类型：functional
- 前置条件：已打开登录页并切换到「验证码登录」；13800138000 可正常接收短信
- 步骤与预期：

  2. 点击「获取验证码」按钮 → 按钮进入 60s 倒计时并提示「验证码已发送」

  4. 点击「登录」按钮 → 页面跳转至首页 /home，顶部显示已登录昵称「测试用户」
