### 改进建议清单（按优先级）

1. 重写两条预期：给出页面位置 + 具体字段/文案 + 空值或非空断言。
2. 重写步骤：补元素名、输入值、URL，删除「提交查询」这类泛化动作。
3. 增「前置条件」字段，明确登录态构造方式与订单归属。
4. 订单号参数化并说明造数；确认是否补充越权/无效单号场景。

### 未覆盖说明

- 溯源：无需求文档，未评估，仅做内部一致性检查。
- 范围相关性：无需求原文，无法判断「未登录查看订单」是否为本次需求范围。
- 覆盖度：TP_VIEW 已各覆盖正/负场景；是否缺越权/无效单号需产品确认。
