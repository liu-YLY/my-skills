## 改进建议清单

1. 步骤补全对象与输入：如「进入「系统配置」页，将「超时时间」由 30 改为 60，点击「保存」」。
2. 预期改为可判定：如「提示「保存成功」；刷新后「超时时间」显示 60；配置表 timeout=60」。
3. 增加验证步骤或改用接口/DB 断言，使后端结果可被观察。
4. 补字段：优先级、类型、测试点编号；ID 规范为 `TC_{模块}_{功能}_{001}`。
5. 补前置数据：配置项初始值与准备方式。
6. 若需求有要求，补字段校验、权限、异常用例。
