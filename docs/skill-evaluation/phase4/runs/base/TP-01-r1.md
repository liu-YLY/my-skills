## 需求理解（快速摘要）

**功能概述**：账号登录模块支持手机号/邮箱两种方式登录，密码强度校验、连续错误锁定与管理员强制解锁。

**本次变更焦点**：

| 焦点项 | 需求依据 | 改动的行为 |
|--------|----------|------------|
| 手机号登录规则 | 需求原文「11 位、1 开头、唯一」 | 新增格式与唯一性校验 |
| 邮箱登录规则 | 需求原文「含 @ 和域名」 | 新增格式校验 |
| 密码强度规则 | 需求原文「8-20 位且必须含字母和数字」 | 新增长度+字符类型校验 |
| 登录锁定策略 | 需求原文「连续 5 次密码错误锁定 30 分钟」 | 新增错误计数与锁定 |
| 管理员强制解锁 | 需求原文「管理员可强制解锁」 | 新增解锁能力与权限 |

**不在本次范围**：注册流程、找回密码、验证码登录、第三方登录、界面视觉（需求未提及）。

**用户角色**：普通用户、管理员。
