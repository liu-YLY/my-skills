## 需求理解（快速模式，仅状态规则摘要）

**功能概述**：订单状态机流转与支付回调幂等控制。

**状态集合**：待支付、已支付、待发货、已发货、已完成、已取消、退款中、已退款。

**合法流转**（需求明示）：
待支付→已支付；已支付→待发货；待发货→已发货；已发货→已完成；待支付→已取消；已支付→退款中；退款中→已退款。

**非法流转**：已完成→退款（需求明确禁止）。其余非法流转（如已取消→已支付、已退款→已发货）需求未明示，按「终态不可再流转」推断，标注待确认。

**幂等要求**：支付回调重复投递不得造成状态或支付结果重复变更。
