## 需求理解（焦点）

| 焦点项 | 需求依据 | 改动的行为 |
|--------|----------|------------|
| 普通成员查看本人报表 | 用户描述 | 新增按本人数据范围的报表查看 |
| 部门管理员查看/导出本部门报表 | 用户描述 | 新增按部门数据范围的查看与导出 |
| 超级管理员查看/导出全部报表 | 用户描述 | 新增全局范围的查看与导出 |
| 未授权访问返回 403 | 用户描述 | 新增权限拦截与 403 响应 |

**系统类型**：权限系统（角色 × 数据范围 × 操作）。
**不在本次范围**：报表生成逻辑、报表内容字段、前端 UI 细节。

**待确认项**：
1. 「本部门」是否含子部门/虚拟部门，待产品确认。
2. 普通成员是否完全禁止导出，当前按「未授权」理解。
3. 403 返回形式（HTTP 状态码 + 提示文案/页面），待需求补充。
