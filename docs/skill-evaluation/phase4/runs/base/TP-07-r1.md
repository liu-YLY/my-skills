## 需求理解（摘要）

**功能概述**：订单支付成功后触发邮件与站内信通知；支持邮件退订，退订不影响站内信；发送失败按 1/5/10 分钟间隔重试 3 次。

**系统类型**：通知/邮件 + 异步任务/重试。

**焦点三档**
| 档位 | 项 | 需求依据 |
|---|---|---|
| 焦点 | 支付成功发邮件；支付成功发站内信；邮件退订；退订后站内信仍发；失败重试 3 次（间隔 1/5/10 分钟） | 口述需求 §1–§4 |
| 回归 | 订单详情/列表展示、邮件模板渲染 | 需求未提，仅冒烟 |
| 范围外 | 支付流程本身、邮件内容编辑、站内信 UI 样式 | 需求未提且不受影响 |

**待确认项**：① 重试适用邮件、站内信还是双通道；② 退订入口与生效时点（实时/下次发送）；③ 3 次全部失败后的处理（标记/告警）；④ 退订是否影响历史已发邮件；⑤ 重试期间退订是否继续重试。
