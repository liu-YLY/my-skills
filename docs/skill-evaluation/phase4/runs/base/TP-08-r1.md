## 测试点清单

**需求拆分**：§1 支持全额/部分退款；§2 退款金额不超过实付；§3 同一订单可多次部分退款但累计不超过实付；§4 退款回调重复不重复退款。
**系统类型**：支付/订单（金额精度、部分退款、状态流转、幂等）。

**覆盖度自检**：7 维度均已判定适用性；焦点为 §1–§4 的退款金额、累计与回调幂等；金额类字段按实付阈值取一组三点（等于/超过、累计等于/超过），未叠加空值、格式等重复取点（合并为参数化）；服务故障类默认 0 条，仅保留需求明确要求的回调幂等；权限与 UI 无需求依据已裁剪并注明。

**待确认项**：退款金额精度（是否精确到分）、部分退款的订单状态取值与可退余额展示口径、回调幂等的判定依据（退款单号/请求 ID）——均标「待产品/需求补充」，确认后补点。
