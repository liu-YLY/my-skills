## 二、改进建议清单

1. 预期统一为「位置 + 具体值/文案」，禁用「成功/正常/正确」。
2. 步骤补齐操作对象、输入值与前置条件（登录态、权限、环境）。
3. 密码、昵称、头像按校验规则参数化拆分，一条只验一个业务目标。
4. 建立术语与动词表（弹窗/对话框、点击/点选）。
5. 补需求文档与测试点基线后重评覆盖度与溯源。
