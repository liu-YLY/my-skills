## 需求理解（信息局限声明）

> 本次未提供需求文档、代码或接口契约，且无该小众硬件调测工具的产品知识文件。以下内容基于通用硬件调测工具能力推断，**全部标「待产品确认」**；缺陷模式库无领域匹配，按 skill 兜底改用通用模式（输入校验/状态/权限/数据/UI）。未读取任何代码与文档。

**功能概述**：桌面端工具通过串口连接自研硬件，完成固件升级、寄存器读写、实时数据观测与日志导出。

**本次变更焦点**（推断）：

| 焦点项 | 需求依据 | 改动的行为 |
|--------|----------|------------|
| 串口连接参数与状态 | 待补充 | 从固定波特率改为可配置并显示连接态 |
| 固件烧录校验与版本控制 | 待补充 | 新增固件版本比对与烧录校验 |

**不在本次范围**：硬件电路本身、产线量产工具、PC 性能基线。
**用户角色**：调测工程师（本地管理员，无多角色差异，权限维度裁剪）。
**业务规则**：1. 连接参数为 115200/8/N/1；2. 固件版本低于当前版本拒绝烧录；3. 烧录后回读校验。
**状态规则**：未连接 / 连接中 / 已连接 / 断开；未烧录 / 校验中 / 烧录中 / 成功 / 失败。
**异常规则**：断连、拔线、文件损坏的处理待产品确认。
**风险分析**：烧录失败导致设备变砖为高风险，列为 P0。
**待确认项**：断连是否要求自动重连与回滚；版本比对规则（允许平级/降级）；寄存器位宽。

### TC_SERIAL_CONNECT_001: 串口 - 使用正确参数连接成功

- **优先级**: P0
- **类型**: functional
- **需求追溯**: 待补充 / TP-01
- **来源**: ai-generated
- **人工审核状态**: not-reviewed
- **业务背景**: 验证按 115200/8/N/1 连接后工具进入已连接态

**前置条件**: 设备已通过串口接入并已上电；当前未连接

**测试步骤**:
1. 在串口下拉框选择设备对应 COM 口
2. 设置波特率 115200、数据位 8、校验位 None、停止位 1
3. 点击「连接」

**关键检查点**: 步骤 3 后：状态标签显示「已连接」
