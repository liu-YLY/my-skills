**裁剪说明（未落测试点）**
- 服务故障类（断网、超时、5xx、依赖不可用）：需求未要求容错 → 默认 0 条。
- 权限/角色差异：需求未提及用户角色 → `范围外：PRD 全文无对应条目`。
- UI 交互（按钮样式、加载动画、提示文案细节）：UI 非本次被测对象 → `低风险：非被测对象，仅冒烟`。
- 关键词长度上限/字符集穷举（emoji、SQL 注入串、前后空格）：需求无阈值 → `低风险：字段无阈值，不取边界`。
- 兼容性/埋点/性能指标：需求未要求 → `范围外`。
- 价格区间重复覆盖（如同时叠加"空值""格式错误"多条）：已合并为参数化一行。

**待确认项**
1. 空关键词提交：返回全部还是提示必填？
2. 价格区间端点：闭区间还是开区间？
3. 排序默认方向（升/降）及是否允许用户切换。
4. 关键词、分类、价格、排序之间的逻辑关系（AND/OR）。
5. 修改任一筛选条件后分页是否重置到第 1 页。
6. "特殊字符"的具体范围界定（是否含 emoji、通配符、引号）。

**覆盖度自检**：7 维度均已判定适用性（正向功能/反向校验/边界与限制/状态联动落点；权限、UI、异常容错已裁剪并注明理由）；有阈值字段（价格区间、每页 20 条）均取一组三点，无阈值字段未展开；服务故障类 0 条；组合条件用判定表避免排列爆炸；待确认规则已单列，不阻塞可执行用例。
