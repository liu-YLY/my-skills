## 需求理解（快速模式，未做完整需求理解）

**功能概述**：订单支付成功后向用户发送邮件与站内信通知，支持邮件退订，通知发送失败按 1/5/10 分钟间隔重试 3 次。

**系统类型**：通知/邮件系统（发送、重复、失败、订阅/退订）+ 异步任务（触发、重试、延迟）。

**焦点项**：
| 焦点 | 需求依据 | 改动行为 |
|------|----------|----------|
| 支付成功触发邮件 | 需求原文 | 新增触发 |
| 支付成功触发站内信 | 需求原文 | 新增触发 |
| 邮件退订 | 需求原文 | 新增退订能力 |
| 退订后站内信仍发送 | 需求原文 | 通道隔离 |
| 失败重试 3 次，间隔 1/5/10 分钟 | 需求原文 | 新增重试策略 |

**待确认项**：
1. 重试是否同时适用于邮件与站内信（需求未区分）。
2. 重试 3 次仍失败后的最终处理（死信/丢弃/人工）未明确。
3. 退订是否可逆（重新订阅）未明确。
4. 重试间隔从首次失败还是每次失败起算未明确。
5. 站内信是否有独立退订/免打扰机制（需求未提，默认无）。
