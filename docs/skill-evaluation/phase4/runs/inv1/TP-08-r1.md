## 需求理解（压缩版）

**功能概述**：订单退款支持全额/部分退款，退款金额与累计金额不得超实付，退款回调需幂等。

**系统类型**：支付/订单系统 → 核心维度：金额精度、重复退款、部分退款、状态流转。

**焦点项**

| 焦点 | 需求依据 | 改动行为 |
|------|----------|----------|
| 全额退款 | 需求原文 | 新增 |
| 部分退款 | 需求原文 | 新增 |
| 退款金额不超实付 | 需求原文 | 新增校验 |
| 多次部分退款累计不超实付 | 需求原文 | 新增累计校验 |
| 回调重复不重复退款 | 需求原文 | 新增幂等 |

**业务规则**：单次退款 ≤ 实付；累计退款 ≤ 实付；累计达实付即视为全额；回调按唯一标识判重。
**状态规则**：待退款 → 部分退款 → 已退款；超额/重复请求拒绝，状态不变。
**待确认项**：金额最小单位与精度；部分退款次数上限；并发退款控制策略；回调判重维度（退款单号 / 订单号+金额）；退款渠道与到账方式。

## 覆盖度自检

- 7 维度已判定：正向、反向、边界、状态、异常容错（幂等/并发）适用；权限/UI 范围外裁剪。
- 缺陷模式映射：命中「金额精度」「重复请求幂等」「状态流转」；资金类高危项已覆盖。
- 边界取点：金额阈值仅取临界内/临界/临界外三点，未全区间穷举。
- 焦点全覆盖，非焦点仅冒烟，服务故障类 0 条（回调幂等属需求明确要求，保留）。
- 待确认项：TP_010 最小单位、TP_014 并发策略、退款渠道与判重维度，依赖产品/需求补充后细化。
