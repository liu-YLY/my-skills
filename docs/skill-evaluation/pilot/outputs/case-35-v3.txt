阶段 1：理解需求（快速模式，压缩）

功能概述：用户修改个人昵称，保存后列表页与详情页显示同一新昵称。
用户角色：已登录的普通用户。
需求追溯：
| 条目 | 需求ID/PRD章节/Story | 备注 |
| 长度 1~20 字符 | 待补充 | 对话轮次#1 |
| 允许中文、英文、数字 | 待补充 | 对话轮次#1 |
| 保存后列表与详情页同步显示 | 待补充 | 对话轮次#1 |
业务规则：
1. 昵称长度为 1~20 字符。
2. 昵称只允许中文、英文、数字，其余字符不允许。
3. 保存成功后列表页与详情页显示同一新昵称。
4. 需求只涉及该字段，无跨模块联动、无状态机、无资金属性。
状态规则：初始状态为原昵称；保存后昵称更新；无状态流转与非法状态。
配置联动规则：无上游配置；下游为列表页与详情页展示；无配置冲突。
默认值规则：昵称默认为账号原昵称。
异常规则：空值、超长、非法字符的提交不写入昵称（提示文案待需求补充）。
数据规则：长度按字符个数计数；非法输入不写入；保存成功后两处展示一致。
风险分析：高风险为长度边界、字符白名单、保存后两处展示一致性；无资金与权限风险。
待确认项：字符计数口径是否含空格、是否按 Unicode 码点（待产品确认）；三类非法输入的提示文案（待需求补充）。
