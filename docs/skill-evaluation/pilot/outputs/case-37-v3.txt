阶段 1：理解需求

功能概述：用户以手机号加验证码登录，并具备错误锁定、记住登录、退出与异地登录提醒能力。
需求追溯：
| 条目 | 需求ID/PRD章节/Story | 备注 |
| 手机号登录 | 待补充 | 对话轮次#1 |
| 验证码错误锁定 | 待补充 | 对话轮次#1 |
| 记住登录 7 天 | 待补充 | 对话轮次#1 |
| 退出登录 | 待补充 | 对话轮次#1 |
| 异地登录提醒 | 待补充 | 对话轮次#1 |
用户角色：未登录访客、已登录用户。
业务规则：
1. 输入手机号与正确验证码可登录，登录后进入首页。
2. 验证码连续错误达到阈值后账号进入锁定状态，锁定期内拒绝登录。
3. 勾选「记住登录」后 7 天内免登录，超过 7 天需重新登录。
4. 点击「退出登录」后会话失效，访问需登录页面跳转登录页。
5. 登录地与常用登录地不一致时触发异地登录提醒。
状态规则：初始状态未登录；状态切换 未登录 → 已登录 → 已退出；锁定为独立状态；会话保存 7 天（勾选时）；状态互斥：锁定与已登录不共存；非法状态：锁定期内登录成功。
配置联动规则：上游配置为验证码错误阈值、锁定时长、7 天计时口径、异地判定依据与提醒渠道；下游行为为锁定、免登录、提醒发送；优先级与冲突处理待需求补充。
默认值规则：「记住登录」默认不勾选（待产品确认）。
异常规则：验证码错误、验证码为空、会话过期、网络异常的处理逻辑待需求补充。
数据规则：会话 token 在退出后失效；锁定计数在锁定期结束后清零；登录地记录用于异地判定。
风险分析：高风险模块为登录认证与锁定（核心路径、安全边界）；高回归风险为退出登录对会话的影响；必须重点测试登录成功、锁定、7 天有效期、异地提醒触发与不触发。
业务系统识别：权限系统（Auth）、通知系统（异地提醒）、状态机系统（锁定/登录态）；按 core.md 补充维度：角色权限矩阵与越权访问、Token 过期、通知链路（发送/不发送/重复/失败）、初始状态与状态切换/保存/刷新后状态/状态互斥/非法流转。
待确认项：验证码错误次数阈值与锁定时长、7 天计时口径（自然日或滚动 168 小时）、异地判定依据与提醒渠道、各类提示文案，均待产品确认。
