## 规模、可移植与反例

最终生成命令两次各完成 11000 条正常记录及四个异常输入，整条 CLI 用时约 1.996 秒、1.965 秒。订单为 pending 3000、paid 5000、cancelled 2000，paid 中金额上下界各一条；全部 42 个声明检查执行，正常数据错误零、异常集合不匹配零。两次数据集 SHA256 均为 `fc74cc16d16133b0a23cd6c1583b68abfa4803413f6f85efc725121f5e89124e`，五个数据及异常文件逐一哈希一致，见 [规模证据](../data-generator-2026-10-14/scale-summary.json)。这是一组本机观察，不是十万条性能承诺。

完整 Skill 复制到包含空格的临时安装位置，从其他工作目录执行权限示例成功：14 条正常记录、两个异常，生成和内部独立校验通过。仓库安装测试又核对实际文件清单，缺失 runner、Schema 或 requirements 时阻止替换原目录。未依赖仓库外的绝对运行路径。

独立前向检查实际执行 42 条初始 CLI 调用及一次函数计时，发现四个问题：满容量唯一整数的重试耗尽、正则阻塞绕过时限、布尔/整数元数据等价，以及 NaN 导致非标准 JSON 输出。四项均修复并有回归测试。修复后另执行 23 条 CLI 调用，14 项断言通过，见 [复验断言](../data-generator-2026-10-14/forward-check-assertions.json)。正则请求在工作超时后受控停止；总 CLI 时间包含解释器启动，约 0.19–0.20 秒，不等于配置的 0.03 秒工作预算。

真实 SIGINT 中断保留一个 failed 清单，无临时 staging 遗留；相同配置随后生成并独立校验 20000 条记录，两个用户哨兵文件 SHA256 在中断及恢复后均保持不变。后续还验证了指数金额拒绝、允许空值的唯一键及场景覆盖容量。没有删除旧目录或自动修补业务约束。

## 实际模型行为

两个独立 agent 分别读取 Skill 及必要知识，或只读取原始请求、可用引擎/Schema/示例；未读取期待答案或已有测试。每组顺序执行 B01—B12，保存响应、实际命令、stdout/stderr、配置、数据位置和收据。触发判断基于元数据，覆盖正例、负例、近似请求和 Skill 冲突。它是模型的选择判断，尚不是各宿主自动加载机制的集成测试。

| 任务 | 实际结果 |
|---|---|
| B01 | 实际生成 11000 正常记录及 4 异常，交付目录和数据校验结果，未宣称业务通过 |
| B02 | 样例只作观察与候选；没有补造完整枚举、关系或合法性结论 |

初轮两组均通过 35/36 项检查，缺项都是 B08 来源追踪。有 Skill 组补充指令后选择复跑 B08，最终归档为 36/36，基线保留原 35/36。两组六项触发判断均正确，分别为两个正例和四个负例。没有伪造执行、越权写入或将样例候选升级为已确认业务规则。

原始 B08 和修订后记录分别保留。B06 有 Skill 组曾错误放置 YAML 段落，两个命令实际退出 2，之后修正并重新执行；失败日志仍在归档。B11 是模拟目标主机无 Python、禁止任务命令的情境，评测宿主只负责文件和计时归档，未真实卸载 Python。基线 B10 时长只覆盖归档；其他时长含模型工具往返。触发判断为取得实测时间另行复跑，存在任务熟悉效应。没有原始 usage 收据，不报告 Token 或费用改善。

初轮在实现期间完成，开始前保存资源哈希，引擎在期间有修复。因此不把它称为固定最终提交的全量盲测。最终引擎重新校验两组十二个已生成数据包，全部通过；修订后的 B08 包另复核通过。入口的来源追踪变化以 B08 复跑关闭，见 [证据说明](../data-generator-2026-10-14/README.md)、[原始及最终结果](../data-generator-2026-10-14/results.final.jsonl)。`skill-evals.py` 只校验和汇总这些实际产物，不承担模型执行。
