## 核心结论

### 1. 准入评级场景：v1.2 是"无损增强"

v1.2 不改变 v1.1 的总分、评级、维度分——所有 v1.1 评分保持兼容。v1.2 只**叠加**新输出段（效果子评级 / 无效改进检测），为决策者多提供一层"效果是否撑得起总分"的判定。

**信息增益**：v1.1 报"91 分 A 级"时，读者无法判断是"结构凑出来的"还是"实际效果优秀"；v1.2 通过效果子评级明确告知"28/33 E-A 级，与总分一致无虚高"。

### 2. 优化循环场景：v1.2 是"虚高克星"

v1.1 在优化循环中**无脑 keep 涨分改动**，无法识别"结构凑分"。v1.2 通过 §12 六条规则识别出"结构涨幅/效果涨幅 = 2.0"的凑分嫌疑，并触发 ×0.5 折扣。

**关键价值**：v1.2 让"为涨分而涨分"的改动被显式标注，迫使优化者证明"涨的是效果分不是结构分"。

### 3. v1.2 的局限

- **规则 3/5 依赖 B3.6 与 paired 数据**：若 dry_run（如 bug-analyzer 场景），规则 3 无法判定、规则 5 无数据，检测能力降级
- **规则 6 主观性**："expected 过弱"的判定阈值（< 20 字符 / 含不可判定词）仍需人工把握
- **规则 1 阈值经验性**：比值 > 2.0 是经验值，可能误判"合理的结构改动"为凑分

### 4. 推荐使用方式

| 场景 | 推荐版本 | 理由 |
|---|---|---|
| 准入评级（一次性） | v1.2（兼容 v1.1） | 无损增强，多一层效果背书 |
| 优化循环（持续改进） | **v1.2 强制** | v1.1 无法识别虚高，v1.2 是唯一选择 |
| 版本对比（v1.2 vs v1.1） | v1.2 | paired + §12 协同判定 |
| 资源受限（无 subagent） | v1.2（降级模式） | B3.6 dry_run 时规则 3/5 失效，但规则 1/2/6 仍可用 |
