# Skill 测评评分模板（通用版）

> 配套 [methodology.md](./methodology.md) 使用的可填写评分模板。平台中立，适用于任何 AI Skill。
>
> 使用方法：
> 1. 复制"空白评分表"到新文件
> 2. 按"填写示例"演示的格式逐维度打分
> 3. 汇总为总分 + 评级 + 优缺点
> 4. 各平台字段名参考 methodology.md §8 跨平台映射表
>
> **v1.1 更新**（2026-08-06，吸收 darwin-skill v2.1 机制）：①A3.3 新增模糊词黑名单扫描（出现 ≥3 处封顶 1 分）②B3 新增 B3.6 baseline 对照可选观察项（不计入 10 分基数）③B5.4 检查清单追加 High-Risk Action 动词黑名单 ④测评方法说明新增 Runtime neutrality 红灯扫描项。详见 methodology.md §6.1 / §7 / A3.3 / B3.6 / B5.4。
>
> **v1.2 更新**（2026-08-06，针对"得分虚高但实际效果不提升"）：①B3.6 从"可选"升级为"推荐"，新增量化增量（+3/+1/-3）②总分后新增效果子评级（B1+B3+B4+B3.6 增量，E-A/E-B/E-C/E-D）③§7 paired 比较增加"改后版潜在退化场景"必填项 ④新增 §12 无效改进识别（6 条检测规则：结构凑分/体积膨胀/baseline 退步/dry_run 失效/paired 乐观偏差/expected 过弱）⑤报告结构加效果子评级与无效改进检测段。详见 methodology.md §5.4 / §7 / §9 / §10 / §12。
>

## 三、使用说明

### 3.1 测评流程

1. **准备阶段**
   - 确认被测 skill 的平台与形态（参考 methodology.md §11 适用范围）
   - 确认测试集可用性（≥10 条，四类用例比例符合 §4.1）
   - 确认可执行环境（Tier B 需要 agent 运行环境）
   - 确认 judge 模型可用（Tier 3 需独立模型）

2. **Tier A 静态评审**
   - 先跑 Tier 1 确定性检查（脚本/正则）
   - 再做 Tier 2 启发式评审（人工 + 统计）
   - 填写 A1-A5 各子项得分

3. **Tier B 运行时测评**
   - 用测试集跑 skill（每条用例执行）
   - 收集 agent 执行日志
   - Tier 1 解析日志（触发率/步骤序列/工具调用）
   - Tier 2 统计（token/澄清次数）
   - Tier 3 LLM-judge（输出质量/鲁棒性）
   - 填写 B1-B5 各子项得分
   - 检查 B5.4 安全硬否决门

4. **汇总**
   - 计算 Tier A 小计 + Tier B 小计 = 总分
   - 判定评级（A/B/C/D）
   - 从维度分推导优缺点
   - 总结系统性问题
   - 给出改进建议（按 P0/P1/P2 优先级）
