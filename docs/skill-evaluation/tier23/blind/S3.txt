# 测试用例集：账号登录（手机号登录 / 验证码错误锁定 / 记住登录 7 天 / 退出登录 / 异地登录提醒）

## 阶段 1：需求理解

**功能概述**：用户通过手机号 + 验证码登录系统，验证码连续错误触发锁定，支持记住登录 7 天免登录，可退出登录，异地登录时向用户发送安全提醒。

**需求追溯**：
| 条目 | 需求ID/PRD章节/Story | 备注 |
|------|----------------------|------|
| 手机号登录 | 需求#37 条目 1 | 无正式 ID，填「待补充」 |
| 验证码错误锁定 | 需求#37 条目 2 | 无正式 ID，填「待补充」 |
| 记住登录 7 天 | 需求#37 条目 3 | 无正式 ID，填「待补充」 |
| 退出登录 | 需求#37 条目 4 | 无正式 ID，填「待补充」 |
| 异地登录提醒 | 需求#37 条目 5 | 无正式 ID，填「待补充」 |

**用户角色**：普通登录用户（需求未区分其他角色）。

**业务规则**：
1. 登录需输入手机号与验证码，两者校验通过后进入系统。
2. 验证码连续输入错误达到锁定阈值后，该账号在一定时长内禁止登录。
3. 勾选「记住登录」后，登录态保持 7 天，7 天内免重新登录。
4. 点击「退出登录」后清除当前登录态。
5. 在新地点/新设备登录时，向用户发送异地登录安全提醒。

**状态规则**：
- 初始状态：未登录。
- 状态切换：未登录 →（手机号+验证码校验通过）→ 已登录；已登录 →（退出登录）→ 未登录。
- 状态保存：记住登录勾选状态持久化，用于 7 天内恢复登录态。
- 状态互斥：锁定状态与已登录状态互斥；锁定期间不可登录。
- 非法状态：锁定期间通过验证码登录应被拒绝。

**配置联动规则**：
- 上游配置：验证码服务（发送、校验、锁定阈值与时长配置）。
- 下游行为：登录态影响受保护页面的访问权限；异地提醒依赖设备/IP 信息采集。
- 配置优先级：无多级配置。
- 配置冲突：无。

**默认值规则**：
- 「记住登录」默认不勾选，即默认关闭浏览器后需重新登录。

**异常规则**：
- 验证码错误：提示错误且累计错误次数，达到阈值后锁定。
- 验证码过期：超过有效期后校验失败。
- 网络异常：登录请求失败时给出失败反馈，不进入已登录态。

**数据规则**：
- 手机号格式：11 位数字。
- 验证码：需求未明确长度与有效期，待产品确认。
- 登录态有效期：勾选记住登录后为 7 天。

**风险分析**：
- 高风险模块：验证码错误锁定（防暴力破解安全边界）、异地登录提醒（账号安全）。
- 高回归风险：登录态管理影响所有受保护页面访问。
- 必须重点测试范围：锁定阈值与解锁、记住登录 7 天边界、异地提醒触发条件。

**待确认项**：
- 验证码错误锁定阈值次数需求未明确（待产品确认），本用例按 5 次假设设计。
- 锁定持续时长需求未明确（待产品确认），本用例按 15 分钟假设设计。
- 异地登录判定规则（按 IP 归属地 / 设备指纹 / 城市）需求未明确（待产品确认），本用例按「新地点」假设设计。
- 验证码有效期与位数需求未明确（待产品确认）。
- 记住登录 7 天自勾选时刻起算（待产品确认）。

- **业务背景**: 验证验证码连续错误达到锁定阈值后账号被锁定，防止暴力破解

**前置条件**:
- 手机号 13800138000 已注册，当前未锁定

1. 在「手机号」输入框输入 `13800138000`
2. 连续 5 次在「验证码」输入框输入错误值 `000000` 并点击「登录」

**业务结果**:
- 第 5 次登录后页面显示「验证码错误次数过多，账号已锁定」

**后置条件**:
- 等待锁定时长过后解锁，或由测试人员后台解除锁定

**标签**: auth, login-lock, security
