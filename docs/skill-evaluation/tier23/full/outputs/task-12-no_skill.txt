登录功能·探索式测试点（不写探索章程，直接给测试点）

一、登录入口与界面
1. 登录页各元素是否正常展示（账号框、密码框、登录按钮、验证码、忘记密码、注册入口）。
2. 键盘交互：Tab 顺序是否合理，回车能否直接触发登录。
3. 占位提示文案是否清晰，密码框是否默认隐藏输入内容。

二、账号/密码输入
4. 已注册手机号 + 正确密码 → 是否登录成功并跳转。
5. 已注册手机号 + 错误密码 → 是否失败并提示，是否不跳转。
6. 未注册手机号 + 任意密码 → 是否失败并提示（注意不泄露"账号不存在"信息）。
7. 手机号为空 / 密码为空 → 是否给出必填校验提示。
8. 手机号格式错误（位数不足、含字母、特殊符号）→ 是否校验拦截。
9. 密码长度边界（最短、最长、超长）→ 是否按规则校验或截断。
10. 输入含空格的手机号/密码（前后空格）→ 是否自动去空格或报错。
11. 特殊字符/emoji/中文输入 → 是否有异常。

三、安全与防攻击
12. 连续多次密码错误 → 是否触发锁定/验证码/冷却，锁定逻辑是否正确。
13. SQL 注入、XSS 载荷输入账号密码 → 是否被安全处理，无注入。
14. 密码是否明文传输（抓包观察），是否走 HTTPS。
15. 登录态是否安全：cookie/token 属性（HttpOnly、Secure、有效期）。
16. 暴力破解：高频请求是否有限流或风控。

四、验证码/多因素
17. 验证码错误、过期、刷新 → 是否正确拦截或刷新。
18. 短信验证码重发限制、有效期、防刷。
19. 多设备同时登录 → 是否互踢或限制，提示是否合理。

五、状态与流程
20. 已登录状态再次打开登录页 → 是否直接进入或给出提示。
21. 登录后刷新页面/关闭重开 → 登录态是否保持。
22. 记住密码/自动登录勾选 → 行为是否符合预期，安全风险。
23. 忘记密码/找回密码入口 → 流程是否可走通。
24. 登录成功后的跳转目标是否正确（原请求页回跳）。

六、异常与兼容
25. 网络异常（断网、弱网、超时）→ 是否有友好提示，不白屏。
26. 服务端返回 5xx → 是否有容错提示。
27. 不同浏览器/移动端/分辨率 → 界面与功能是否正常。
28. 输入超长字符串、粘贴大文本 → 是否崩溃或卡顿。

七、数据与边界
29. 登录成功后的用户数据（昵称、权限、收藏等）是否与账号一致。
30. 密码大小写敏感性 → 是否符合定义。
31. 账号被禁用/冻结/注销状态登录 → 是否给出对应提示。
