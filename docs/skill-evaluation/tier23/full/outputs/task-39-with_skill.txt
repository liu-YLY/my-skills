## 需求理解

**功能概述**：Webhook 创建——通过配置 Version、Trigger、Endpoint URL 并点击 Add endpoint 创建一条 Webhook。

**业务系统类型**：第三方对接（Webhook 回调），含输入校验与安全风险。

**需求追溯**：

| 条目 | 需求ID/PRD章节/Story | 备注 |
|------|----------------------|------|
| Webhook 创建表单 | 待补充 | Version 下拉框、Trigger 选择框、Endpoint URL 输入框、Add endpoint 按钮 |

**用户角色**：拥有创建 Webhook 权限的用户。

**业务规则**：
1. Version 为下拉框选项。
2. Trigger 为选择框选项。
3. Endpoint URL 为必填项，需为合法 URL 格式。
4. 表单填写完整后 Add endpoint 按钮可用，点击后创建 Webhook。

**风险分析**：
- 高风险模块：Endpoint URL 校验（必填、格式）、URL 注入（XSS/SSRF）。
- 高回归风险：Webhook 创建成功后的列表展示。
- 必须重点测试范围：URL 必填/格式/注入、按钮状态联动、创建成功。
