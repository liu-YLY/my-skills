登录功能测试用例（快速版）

一、正向用例

用例编号：Login_001
标题：手机号+正确密码登录成功
步骤：进入登录页 → 输入已注册手机号 → 输入正确密码 → 点击登录
预期：登录成功，跳转首页，显示用户信息

用例编号：Login_002
标题：邮箱+正确密码登录成功
步骤：切换到邮箱登录 → 输入已注册邮箱 → 输入正确密码 → 点击登录
预期：登录成功，跳转首页，显示用户信息

二、负向用例

用例编号：Login_003
标题：手机号+错误密码登录失败
步骤：输入已注册手机号 → 输入错误密码 → 点击登录
预期：提示"手机号或密码错误"，不进入系统

用例编号：Login_004
标题：邮箱+错误密码登录失败
步骤：输入已注册邮箱 → 输入错误密码 → 点击登录
预期：提示"邮箱或密码错误"，不进入系统

用例编号：Login_005
标题：未注册手机号登录失败
步骤：输入未注册手机号 → 输入任意密码 → 点击登录
预期：提示未注册或账号密码错误

用例编号：Login_006
标题：手机号格式错误
步骤：输入 10 位手机号 → 输入密码 → 点击登录
预期：提示手机号格式错误，请求不发送

用例编号：Login_007
标题：邮箱格式错误
步骤：输入缺少 @ 的字符串 → 输入密码 → 点击登录
预期：提示邮箱格式错误，请求不发送

三、空值与边界用例

用例编号：Login_008
标题：空账号
步骤：不输入账号 → 输入密码 → 点击登录
预期：提示请输入账号

用例编号：Login_009
标题：空密码
步骤：输入账号 → 不输入密码 → 点击登录
预期：提示请输入密码

用例编号：Login_010
标题：连续多次密码错误触发锁定
步骤：连续 5 次输入错误密码 → 第 6 次登录
预期：账号锁定，提示稍后再试

四、安全用例

用例编号：Login_011
标题：密码传输加密
步骤：抓包观察登录请求
预期：密码不以明文传输

用例编号：Login_012
标题：登录失败提示不泄露账号是否存在
步骤：分别用存在/不存在的账号错误密码登录
预期：提示文案一致，不区分账号是否存在
