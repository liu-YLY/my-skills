修改昵称功能测试用例

需求说明
- 功能：修改昵称（单字段功能）
- 字段规则：长度 1–20 字符
- 允许字符：中文、英文、数字
- 保存后：列表页与详情页同步显示最新昵称
- 范围：仅涉及该字段，无跨模块联动

用例编号：TC35-001
用例标题：昵称保存成功后列表页与详情页同步显示
前置条件：已登录；存在一个可修改昵称的账号
测试步骤：
1. 进入修改昵称页面
2. 输入合法昵称「测试昵称A1」
3. 点击保存
4. 返回列表页查看该账号昵称
5. 进入详情页查看该账号昵称
预期结果：
1. 保存成功，提示保存成功
2. 列表页显示「测试昵称A1」
3. 详情页显示「测试昵称A1」
4. 两处昵称一致
