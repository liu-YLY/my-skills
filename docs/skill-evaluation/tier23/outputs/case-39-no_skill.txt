Webhook 创建功能测试用例

需求说明
- 功能：Webhook 创建
- 界面控件：
  1. Version 下拉框
  2. Trigger 选择框
  3. Endpoint URL 输入框
  4. Add endpoint 按钮
- 要求：每条用例标题能够独立定位测试点

用例编号：TC39-001
用例标题：Version 下拉框默认值展示正确
前置条件：进入 Webhook 创建页面
测试步骤：
1. 查看 Version 下拉框默认选中项
预期结果：Version 下拉框显示默认选项（如最新版本），可正常展开
