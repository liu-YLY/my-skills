# 缺陷模式库索引（共享引用）

> **何时阅读**：根因分析阶段需要查阅缺陷模式时加载本索引，再决定是否加载完整缺陷模式库。

## 共享来源

完整缺陷模式库位于 `../test-case-engineer/knowledge/bug-patterns.md`，由 test-case-engineer 主维护；本 skill 通过相对路径引用，避免内容重复与分叉。

> **降级策略**：若共享文件不存在（单独安装场景），以下方「内容速览」的模式分类为线索，结合通用测试经验继续分析，不中断流程；输出注明「未查阅完整缺陷模式库，分析基于通用模式」。

## 使用方式

在复现、定位、报告和防御性测试点反推阶段，按需参考共享库中的「{章节名}」，如「状态与流程类」「领域特定缺陷模式 - 支付/金额」。

## 内容速览

- 通用缺陷模式（5 类）：输入校验 / 状态与流程 / 权限与安全 / 数据与接口 / UI 与交互
- 领域特定核心模式：支付/金额 / 搜索/筛选 / 通知/消息 / 文件上传
- 安全专项检查清单（10 项）
- 「功能特征 → 缺陷模式」自动映射表
- 运行时高频错误 checklist：NPE / 500 错误 / 超时，见 `../test-case-engineer/knowledge/runtime-error-patterns.md`
