## 5. 必测内容

### [P0][API/权限] 普通成员无法删除他人项目

- **为什么受影响及边界**：项目列表删除 → 删除接口 → 已读中间件/服务未拒绝成员 → 数据删除；直接影响，未读入口不据此扩大范围。
- **前置条件**：普通成员账号已登录，拥有目标项目查看权限，但没有删除权限。
- **操作**：调用 `DELETE /api/projects/{id}`。
- **预期结果**：
  - 接口返回 403
  - 项目记录未被删除
  - 关联数据保持不变
- **预期来源**：已给管理员限制需求和 403 拒绝契约；没有审计规则，不添加日志断言。
- **测试方式**：业务 API 核对响应和真实测试库中的项目/关联数据；单元验证拒绝分支不调用删除服务，页面权限表现需另行验证。
- **证据**：删除接口及完整调用路径的已读位置/版本。

### [P0][API/权限] 订单导出权限范围待核实

- **为什么受影响及边界**：订单管理导出 → 导出接口 → 移除角色中间件 → 导出服务；直接影响入口限制，是否应允许成员待确认。
- **前置条件**：普通成员账号已登录。
- **操作**：调用 `GET /api/orders/export`。
- **预期结果**：
  - 权限规则、状态码及可返回数据范围待产品/契约确认
- **观察项**：响应状态、返回数据范围、其他角色差异。
- **测试方式**：不同角色调用实际导出 API 并核对数据范围；静态中间件变化不能证明环境权限验证通过。
- **证据**：订单导出接口去除了 admin 校验，疑似超范围；不能把待确认权限规则直接写成 403 验收。

### [P1][兼容性] 历史用户空头像的读取与展示

- **为什么受影响及边界**：历史用户访问资料 → 查询接口 → users.avatar 空值 → 资料展示；空值消费路径需回归，默认占位策略未知。
- **前置条件**：数据库中存在 avatar 字段为 NULL 的历史用户。
- **操作**：登录该历史用户，访问 `/profile` 页面。
- **预期结果**：具体空值展示与接口行为待确认，不默认要求占位符或某个状态码。
- **观察项**：页面渲染、响应状态、空值传递与报错情况。
- **测试方式**：历史空值账号访问页面并检查接口响应；组件测试覆盖空值分支，不能代替实际页面验证。
- **证据**：users.avatar 为新增 nullable 字段，历史数据无值。
