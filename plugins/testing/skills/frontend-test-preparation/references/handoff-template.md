# 索引与需求交接模板

这是字段提示，不是已验证的项目事实。按范围裁剪，缺失信息说明原因。可复用索引与单需求准备记录分开；不要把整份模板复制到每个模块。

## 主索引：docs/testing/frontend-navigation.md

默认完整路径为 `<仓库根目录>/docs/testing/frontend-navigation.md`；其他位置记录实际路径及原因。

- 仓库与导航发现：仓库根目录、发现提交、相关工作区变更、生成/更新时间。
- 覆盖范围：已发现模块、已深入范围、未扫描或未知区域。
- 模块目录：模块标识、检索关键词、源码范围、模块文件相对链接、覆盖状态。
- 导航变更与遗留项：新增/移除模块、失效链接、待处理影响。

大项目主索引只存目录信息，模块文件默认保存到 `<仓库根目录>/docs/testing/frontend-index/模块标识.md`。主索引内引用模块文件时使用相对路径 `frontend-index/模块标识.md`。所有链接以所在文件为基准且指向真实文件；只创建有内容的模块文件。主索引更新时间不代表所有模块和页面已复核。

## 模块索引：docs/testing/frontend-index/模块标识.md

- 模块范围：源码目录、导航发现的入口配置、已扫描与未深入范围。
- 增量基线：覆盖范围内已检查的提交、相关未提交路径及内容指纹；未处理完整则保留旧基线。
- 更新记录：比较范围、已更新/复用条目、实际读取范围、待更新页面及影响原因/来源版本。任务外影响登记待更新，不默认深入；解决后移出清单。

每个页面用模块内稳定唯一标识与名称作为标题，字段按需填写：

- 路由与参数、菜单或其他入口；名称/路由改变时保留原标识与旧别名。
- 组件、守卫、开关、接口、相关测试的代码位置与关键符号。
- 关联源文件和已追踪共享依赖的准确路径/引用；共用说明集中记录，未知关系标为待确认。
- 代码有效性检查提交及覆盖依赖：用于下次优先判断本页复用；有待处理差异时不推进。
- 最后深入读取提交：只记录实际深入；仅核对差异或复用时不更新该值，未深入则说明仅完成导航定位。
- 证据状态、依据、适用范围及未决项。
- 若有运行证据：原证据状态、环境、脱敏角色/租户、部署版本状态、实际核实时间和附件位置；另列对本次任务的适用性，不将旧观察记为本次已执行。

模块过长可按实际子模块拆分并维护入口链接。索引只保留导航和代码关系；详细数据、步骤、预期放入需求记录。

## 单需求准备记录

- 需求标识、来源与版本、涉及条款；设计稿来源、节点与版本。
- 主索引位置、相关模块/页面及当前代码版本。
- 环境、脱敏身份/租户、部署对应依据、当次授权和核实时间；未知或不一致时说明影响。
- 入口与前置条件、最小数据及关联对象、查找办法、创建/清理方案和授权状态。方案已列出不代表数据已就绪。
- 已完成阶段、复用/更新/待更新页面与原因、运行未验证原因、剩余阻塞。

每个操作/检查点记录：编号、需求条款或设计节点、前置状态、动作与定位线索、正确预期及依据、当前实现与代码位置、证据状态、实际结果、检查结果和证据位置。

证据状态使用“代码推断、运行已验证、待确认”；检查结果使用“通过、失败、阻塞、未执行”。没有实际执行或预期依据不足时不判通过。冲突项列出双方证据、影响范围、可自行查证的下一步及仍需确认的具体问题。不保存密码、令牌或客户原始数据。

## 直接使用 Codex 执行时的提示

```text
执行这些用例前，先读取已交付的主索引实际路径，
按模块链接和页面条目定位入口、角色及数据条件。
核对索引版本，必要时用 $frontend-test-preparation 增量更新。
本次只刷新用例相关条目，其他影响登记待更新。
再在本次授权范围内操作页面，以用例和需求依据判断结果。
```

交接给新任务时同时提供可访问的仓库/索引位置和需求记录。该提示不授予业务写入或其他外部操作权限。
