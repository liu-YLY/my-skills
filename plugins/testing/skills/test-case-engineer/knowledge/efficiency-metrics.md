# 效率度量输出

> **何时阅读**：阶段 4 自检完成后生成效率报告时读取；用户不要求效率度量时可跳过。
> **覆盖范围**：效率度量报告模板与传统工时估算基准。

## 效率度量输出（AI 生成模式必做）

阶段 4 自检完成后，输出效率报告：

```markdown
## 效率度量报告

| 指标 | 本次值 |
|------|--------|
| 用例总数 | X 条 |
| AI 生成 | Y 条 (Z%) |
| 人工补充 | W 条 |
| 预估传统工时 | N 人天 |
| 实际工时 | M 人天 |
| 工时节省 | (N-M)/N * 100% |
| 效率提升 | N/M 倍 |

**质量观察**：
- AI 生成用例中需修改的比例：约 A%
- AI 补充的异常/安全场景数量：B 条
```

**传统工时估算基准**：
- 低（单表单/单页面，3-5 字段）：0.5 人天
- 中（多表单/多页面，含联动/权限）：1-2 人天
- 高（复杂业务流程，多角色多状态）：3-4 人天
- 极高（跨系统集成，核心业务链路）：5+ 人天
