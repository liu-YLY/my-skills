# 效率度量输出

> **何时阅读**：阶段 4 自检完成后生成效率报告时读取；用户不要求效率度量时可跳过。
> **覆盖范围**：效率度量报告模板与传统工时估算基准。

## 效率度量输出（AI 生成模式必做）

阶段 4 自检完成后，输出效率报告：

```markdown
## 效率度量报告

| 指标 | 本次值 |
|------|--------|
| 用例总数 | X 条 |
| AI 生成 | Y 条 (Z%) |
| 人工补充 | W 条 |
| 预估传统工时 | N 人天 |
| 实际工时 | M 人天 |
| 工时节省 | (N-M)/N * 100% |
| 效率提升 | N/M 倍 |

**质量观察**：
- AI 生成用例中需修改的比例：约 A%
- AI 补充的异常/安全场景数量：B 条
```

**传统工时估算基准**：
- 低（单表单/单页面，3-5 字段）：0.5 人天
- 中（多表单/多页面，含联动/权限）：1-2 人天
- 高（复杂业务流程，多角色多状态）：3-4 人天
- 极高（跨系统集成，核心业务链路）：5+ 人天

## 可读性观察（可选）

用户要求评估可读性，或需要对比迭代前后时追加。只作趋势参考，不设达标线，不用于质量评级或绩效。

| 指标 | 定义 | 计算方式 |
|------|------|----------|
| 标题可定位率 | 不看步骤即可说出对象、条件、预期的标题占比 | 可定位标题数 / 用例总数 |
| 长句占比 | 含超过 40 字构件的步骤或预期占比 | 长句数 / 步骤与预期总条数 |
| 填充步骤占比 | 复述前置、无信息量导航、解释性文字占步骤总数 | 填充步骤数 / 步骤总数 |
| 术语不一致处数 | 同一对象或动作出现多种叫法的处数 | 人工或检索统计 |

**口径约束**：
- 分母写清范围（全部用例 / 抽样用例）；抽样需注明样本量与抽取方式
- 只报事实与位置，不折算成「可读性得分」
- 不引入 Flesch 等英文可读性公式对中文文本打分
