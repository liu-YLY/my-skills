# 业务泳道图怎样缩放和联动

这份说明以原版 `reward-refactor-review.html` 中实际生效的 `review-flow-v9`、最终样式和普通券页面为依据。可直接打开[独立 HTML 样板](../assets/swimlane-review.html)体验。样板另外保留了本轮约定的用例级反向定位。

## 两个视图服务于不同的阅读动作

| 操作 | 图应该怎样变化 |
| --- | --- |
| 打开一个业务域 | 默认“聚焦本环节”。按首个环节所包含的节点取景，先读得清动作和责任方。选择“全部环节”时恢复完整范围。 |
| 切换环节 | 汇总该环节各测试点关联的节点，再补上只指向环节的入口。一次容纳这些节点，弱化其他环节。控件和图保持在原位。 |
| 选测试点或有明确分支的用例 | 直接验证的节点最醒目。将相连路径和必要上下游一起纳入画面，读者能说出“怎样到这里，随后会怎样”。 |
| 切到“流程全图” | 恢复初始完整 SVG 坐标范围，按面板宽度排版。原图过长时在面板内滚动，将当前节点带回视野；点和用例仍保持选中。返回聚焦时按当前选择重新取景。 |
| 改窗口大小、连续快速选点 | 按新面板尺寸重算取景。后一次选择中止前一次过渡。启用减少动态效果时直接到位。 |

**全图保留整张图的坐标和浏览范围。** 原版普通券图的坐标范围为 `0 0 1120 1210`。恢复后允许纵向滚动。简单地把整张长图缩成一屏，会让节点说明难以辨认。浏览器页面缩放和固定倍数按钮也无法表达“当前测试点关心哪一段”。

## 怎样计算聚焦范围

- 环节视图取该环节所有相关节点。测试点视图取主节点、其他直接关联节点、它们之间的途经节点，以及上下游。无选中范围时使用原始全图。
- 原版为展示关联，在已有连线上查找主节点到其他关联节点的短路径，查找时可沿任一方向走。**箭头仍按原业务方向绘制。** 有环时去重；不连通的节点可同时突出，不补造一条转移。
- 原版以每个直接关联节点为起点，补最多上游两步和下游一步。检查条件分叉、前一步已提交和下游失败时，这个范围通常足够。途经节点与上下游都是上下文，避免把它们统计成新增覆盖。
- 由节点矩形计算外框，留出箭头、文字和序号的空间。原稿每条泳道宽 280 个 SVG 单位，默认至少保留三条完整泳道，实际不足三条就全部显示；纵向约留顶部 70、底部 50 个单位。根据面板宽高比修正视框和边界。单位随画布设计调整。
- 取景切掉原列头后，在图顶端显示当前可见泳道的名称，并把名称对齐到对应列中心。刚好靠近顶部时尽量保留原列头。原版采用约 320 毫秒的缓出过渡，中途切换从当前画面接续。浏览器窗口改变后重新计算。

## 展示上要看出哪些区别

| 元素 | 原版的视觉做法 |
| --- | --- |
| 泳道与普通节点 | 角色列头、淡色交替列底。业务动作浅蓝，支撑操作白底细边，分支为浅琥珀底和虚线边。节点主标题写动作，副标题说明一个条件或结果。 |
| 主线与分支 | 主线用有方向的实线；替代、失败分支用暖色虚线，贴近连线写条件。缩放时箭头和条件随节点一起移动。 |
| 当前测试点 | 直接关联的节点蓝色粗边、浅蓝底，圆形步骤号变为实底。途经节点用较轻的蓝边，相连路径和标签加深。上下游保持可读；无关节点和线条降低对比度。 |
| 稳定步骤号 | 原版沿箭头顺序编号，同阶段用位置打破并列，遇环时稳定选取节点继续。复用已有图时保留原号，补绘恢复连线也保留已经引用的步骤号。图上的号与右侧标识一致；编号只辅助讲解，数据关联使用稳定 ID。 |
| 操作反馈 | 原版用两个并列按钮显示当前视图。悬停图中节点或右侧步骤标识可互相提示；点击才改变当前选择。支持按钮、键盘和触屏操作。F 可切换视图，输入或选择字段中保留正常按键功能。 |

图例至少能辨认主线与分支。选中测试点后，再说明“本测试点、相连流转、上下游”。动画可加强路径辨认，也应能停用。窄屏可上下排列图和阅读区；完整图面较宽时允许局部横向滚动，避免撑宽整个页面。

## 用原版样例验收

1. 打开普通券的商家配置，再选择撤销与退分。视框应移动到相应的业务区域，责任方和节点标题可辨认。
2. 选择 `TP-NOR-030`。图中“订单实际使用优惠券”和“回写使用结果”都是直接关联节点，中间的订单事件可见，上下游显示为背景信息。
3. 找到余额少 1 分的结账页用例。点标题展开正文，点同一卡片旁的“定位流程”反查图，重点应落在“条件不满足”。再次激活该节点能回到刚才的用例。这个粒度属于本轮补充要求。
4. 在该点切到“流程全图”，确认坐标范围恢复且当前节点可找到。切回聚焦，检查选中项、用例和步骤号一致。再测试连续换点、改变窗口宽度和减少动态效果。
5. 用仅关联到环节的入口、无关联的节点或重复经过同一节点的流程检查边界。取景可以退回环节或全图，界面应如实说明关联粒度。

## 复用样板

先保存独立业务 JSON，通过固定生成脚本生成页面。需要迁移已有独立 HTML 时，生成器会读取其中的 `review-data`。样板使用 `lanes`、`stages`、`nodes`、`edges` 和 `points`，节点的 `lane`、`row` 从 0 开始，边的 `a`、`b` 引用节点 ID。测试点的 `nodes` 指向验证位置，用例嵌在各测试点的 `cases` 中，必要时用用例自己的 `nodes` 细分分支。图中示范的业务、三列布局和记录数量均可替换。独立样板不依赖源评审文件或网络。

Skill 附带的精简 JSON 用来讲清关联和检查断链，它把用例放在顶层，字段不同。使用该示例渲染 HTML 时须先转换字段与归属关系。
